3 Research Methodology 3.1 Study design This study evaluates promptable segmentation models on two-dimensional colonoscopy images. Each prediction is made from one image and its prompt. The main comparison uses a common evaluation split, an annotation-derived box and the same outcome definitions. This setup allows the performance of zero-shot and polyp-adapted configurations to be compared under a common prompting protocol. RQ1 examines zero-shot SAM and MedSAM. RQ2 compares zero-shot baselines with models adapted using the full Kvasir-SEG training partition. RQ3 explores variation in performance under different prompt settings and in groups defined by foreground area and boundary contrast. Table 3.1 maps these questions to the experiments. The annotation-budget comparison supplements RQ2. It uses the recorded SAMed and PP-SAM runs with 1, 5, 10 and 880 labelled training images. The smaller support sets come from the same training partition. A separate 5-shot SAMed pilot crossed three optimisation seeds with fixed and redrawn support settings, yielding six training runs. The pilot used a 12-epoch schedule at a learning rate of 0.0005 and evaluated the final checkpoint. It used the full Kvasir validation split and one frame from each of the 29 locally indexed CVC sequences. The shortened schedule and the sampled CVC set define a separate repeatability analysis. 3.2 Datasets and partitioning Kvasir-SEG provides endoscopic polyp images and pixel-level masks [1]. In this study, the filename lists specify 880 training images and 120 validation images. The lists have no overlapping identifiers. Adaptation uses the training partition. The validation partition is used for model selection where applicable and for reporting within-dataset performance. CVC-ClinicDB was used for cross-dataset evaluation [2]. The evaluated set contains 612 annotated frames. No CVC-ClinicDB images were used to fit or select the polyp-adapted checkpoints in the main comparison. Local frame metadata group these 612 images into 29 sequences for the exploratory statistical analysis in Section 3.6.1. ETIS-LaribPolypDB and CVC-ColonDB provide additional evaluations of the fixed SAM ViT-B and MSA-B configurations. For each external dataset, encoded image files were compared by exact SHA- 256 hash against the local Kvasir-SEG and CVC-ClinicDB sets and against the other external set. Within each external set, repeated images with identical binary annotations were represented once. Groups with conflicting binary annotations were excluded. The resulting evaluation used 190 ETIS- LaribPolypDB images and 342 CVC-ColonDB images. This audit detects identical encoded files and retains the possibility of overlap through re-encoding or model pretraining. Zero-shot here indicates that these checkpoints were evaluated without polyp-specific fitting in this project. Ground-truth-derived prompts were supplied during inference for all configurations in the main comparison. The adapted group includes rank-four low-rank adaptation (LoRA) configurations based on SAMed [5] and MedSAM, and polyp-trained Medical SAM Adapter configurations with ViT-B and ViT-L backbones [6]. The adapter configurations are referred to as MSA-B and MSA-L. The main adaptation comparison uses the checkpoints trained with all 880 Kvasir training images. Comparisons with zero-shot configurations use the closest available initial weights and backbone as the reference. For example, MedSAM with LoRA is compared with zero-shot MedSAM. The wider comparison 2 describes the performance of complete model configurations, which can differ in training recipes, input resolution and mask selection. PP-SAM is an existing polyp adaptation method based on perturbed box prompts [7]. In the project implementation, it serves as a full-encoder fine-tuning reference. The evaluated training recipe left the mask decoder frozen. Training details and trainable modules are documented in Chapter 4. Results from methods evaluated without the default annotation-derived box belong in separate comparisons because the input information differs. 3.4 Prompt construction and variants The default evaluation prompt was derived from the tight bounding box of the annotated foreground in the original image. Let the box coordinates be x_min, y_min, x_max and y_max, with maxima defined by the foreground pixel indices. Each minimum is decreased by the chosen expansion and each maximum is increased by the same amount. The resulting coordinates are clipped to the image bounds using the evaluation code's coordinate convention. The default expansion is 30 pixels. Prompt generation takes place before any model-specific coordinate transformation. The same prompt is supplied to every configuration in the main comparison. The expansion experiment uses deterministic outward expansions of 0, 10, 30 and 50 pixels on selected trained configurations. Its analysis uses runs with traceable raw outputs for the plotted comparisons. The local SAMed expansion series uses its own 30-pixel rerun, while the main comparison retains the formal SAMed checkpoint evaluation. The training-time random box perturbation in PP-SAM serves a separate purpose from these fixed evaluation settings. The point and box-translation experiments use zero-shot SAM ViT-B and MSA-B. For translations, the 30-pixel reference box is shifted in each cardinal direction. The requested displacement is 5% of the corresponding image dimension, rounded to a whole pixel. When the image edge prevents the full shift, the displacement is reduced while box width and height are preserved. The overall analysis retains these cases. A supplementary comparison records results for the subset that received the full requested displacement in each direction. Point prompts are derived from the same annotation. One condition uses the foreground pixel farthest from the background, with ties resolved in row-major order. A second condition adds one sampled negative point from the background using base seed 24. A third condition samples one positive point uniformly from the foreground for each of three base seeds (24, 42 and 1234). The seed for a frame is derived from the base seed and a stable hash of the image identifier. Within each model, its decoder and mask-selection settings are held constant across prompt conditions. 3 3.5 Evaluation and subgroup analysis 3.5.1 Evaluation metrics Metrics are computed between a binary prediction and the reference mask at native image resolution. Let TP, FP and FN denote the numbers of true-positive, false-positive and false-negative foreground pixels. The Dice coefficient is 2TP/(2TP + FP + FN), and intersection over union (IoU) is TP/(TP + FP + FN). Precision is TP/(TP + FP), and recall is TP/(TP + FN). Reported precision follows the archived implementation's convention of assigning 1 when the prediction contains no positive pixels. For an empty prediction on an image with annotated foreground, Dice, IoU, recall and boundary F1 are zero. The reported segmentation means give one weight to each evaluated image. Standard deviations, where reported, describe variation across images. Boundary F1 measures contour agreement. A boundary pixel is obtained from the difference between a foreground mask and its four-connected erosion. The matching tolerance is 0.5% of the image diagonal, rounded to a whole pixel with a minimum of one pixel. Boundary precision is the proportion of predicted boundary pixels within the tolerance of the reference boundary. Boundary recall uses the reverse direction. Their harmonic mean gives boundary F1. Surface HD95 describes contour distance. For each boundary pixel, find the distance to its nearest point on the other boundary. Take the 95th percentile separately in each direction and report the larger value in original-image pixels. Surface HD95 is undefined for an empty prediction and the table gives the number of finite measurements. The same implementation was applied to saved predictions in all 28 rows of the main results table. The saved predictions were reconciled against the recorded overlap metrics before recomputation. 3.5.2 Image subgroup definitions Relative polyp area is the fraction of original-image pixels labelled as foreground. The primary groups use area fractions of at most 5%, greater than 5% up to 20%, and greater than 20%. A sensitivity analysis also uses the area tertiles estimated from the 880 Kvasir training masks and applies those cutoffs to both primary evaluation sets. Each area group describes how much of the image is occupied by annotated foreground. Boundary contrast is the Euclidean distance between the mean CIELAB colours in narrow bands immediately inside and outside the annotated boundary. The primary band width is 0.5% of the image diagonal, rounded to the nearest pixel with a minimum of two pixels. The lower and upper quartiles within each dataset define the low, intermediate and high contrast groups. Alternative band widths and the median grayscale gradient magnitude along the annotated boundary provide sensitivity checks. Area and contrast groups are also crossed to examine how their overlap may affect the descriptive results. 4 3.5.3 Inference timing SAM ViT-B, SAM ViT-L and MSA-B were benchmarked at batch size one on an NVIDIA GeForce RTX 4070 Ti SUPER. Thirty images from each primary dataset were sampled without replacement using a fixed seed. After five warm-up images per dataset and configuration, the same 30 images were used in three timed passes. GPU work was synchronised around each timer. Latency includes model-specific preprocessing, image encoding, prompt decoding and returning the mask to the host. The timed interval excludes disk reads, model loading and prompt generation. Each model retained its configured input resolution. Frames per second are computed by dividing 1,000 by the mean latency in milliseconds. 3.6 Statistical analysis and validity 3.6.1 Statistical comparisons For the point and box-translation study, the effect for a frame is the metric under the tested prompt minus the metric under that frame's 30-pixel reference box. The three trials for the random-positive condition are averaged within each frame before aggregation. This yields a matched comparison of prompts for each configuration. For CVC-ClinicDB, frame-level Dice changes are averaged within each of the 29 video sequences, then averaged equally across sequences. The exploratory analysis considers 21 contrasts across seven nonreference prompt conditions. These comprise the paired change within SAM ViT-B, the paired change within MSA-B and the difference between the two configurations' paired changes. Two-sided Monte Carlo sign-flip tests use 100,000 draws and assume independent, symmetric sequence-level paired differences under the null. Holm correction is applied across all 21 contrasts. Unadjusted 95% percentile intervals are obtained by bootstrapping sequences. Kvasir prompt results and the image subgroup comparisons are reported descriptively. 3.6.2 Validity of comparisons The annotation-derived box and points provide lesion location information during evaluation. The resulting comparisons characterise segmentation under supplied prompts. The validation scores for Kvasir-SEG also reflect checkpoint selection, and the local CVC sequence groups define the sampling unit for the statistical analysis. The area and contrast analyses were conducted after the primary experiments. A fixed expansion in pixels changes the box size proportionally more for smaller boxes, so differences between area groups may reflect a combination of foreground scale and prompt geometry. The colour and gradient measurements are image-derived proxies for boundary visibility and can be affected by illumination, texture and reflections. Expert boundary ratings would be needed to determine how closely these proxies agree with human assessments.
