# AI-assisted architecture illustrations

These prompts were used with built-in ImageGen. The generated visuals were checked against the project implementation and the cited architecture figures. Models and prompt conditions shown are schematic.

Figure references include [SAM Fig. 4](https://openaccess.thecvf.com/content/ICCV2023/papers/Kirillov_Segment_Anything_ICCV_2023_paper.pdf), [SAMed Fig. 3](https://arxiv.org/pdf/2304.13785), [Medical SAM Adapter Fig. 1(b)](https://doi.org/10.1016/j.media.2025.103547) and [PP-SAM Fig. 1](https://arxiv.org/pdf/2405.16740). The [MELBA fine-tuning comparison, Fig. 2](https://www.melba-journal.org/pdf/2025%3A006.pdf) provided a layout reference for distinguishing shared and trainable modules. [ASPS](https://papers.miccai.org/miccai-2024/paper/4128_paper.pdf) and [SAM-Mamba Fig. 1](https://openaccess.thecvf.com/content/WACV2025/papers/Dutta_SAM-Mamba_Mamba_Guided_SAM_Architecture_for_Generalized_Zero-Shot_Polyp_Segmentation_WACV_2025_paper.pdf) provide further examples of visualizing newly added branches.
